About this vault

A zettelkasten for Module 2

The zettelkasten method breaks knowledge into small, atomic notes and connects them with links instead of folders. This site converts the Cloud Computing M2 slide deck into 80 interlinked cards, so you can study by following ideas rather than by flipping slides.

  • / focus search  ·  n new note  ·  Esc close
  • Click any underlined reference to jump to that note.
  • Open Graph to see the whole network. Drag nodes, click to open, hover to highlight connections.
  • Your own notes are stored only in this browser. Export a JSON backup before clearing browser data.
